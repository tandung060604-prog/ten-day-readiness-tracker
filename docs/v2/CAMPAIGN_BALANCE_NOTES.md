## 2. Blocker Scaling Formulas

- **Chapter 1 (Levels 1–10)**:
  - Max blockers: 0–6 wooden crates (`crate`).
  - Tile density: 4–5 character types.
- **Chapter 2 (Levels 11–20)**:
  - Max blockers: 6–10 wooden crates.
  - Specials requirement: 2–3 line rockets/rainbows.
  - Tile density: 5–6 character types.
- **Chapter 3 (Levels 21–30)**:
  - Max blockers: 6–12 wooden crates in tactical formations.
  - Specials requirement: 3–4 activations.
  - Tile density: 6 full character types.

## 4. Gentle Failure UX & Accessibility
- **No Monetization / Paywalls on Failure**: If moves run out, companions display encouraging animations and allow instant zero-penalty replays.
- **Colorblind & Low-Vision Accessibility**: Every tile features distinct, iconic silhouette characteristics (e.g. Usagi long yellow ears, Hachiware blue forehead triangle, Momonga white bushy tail, Kurimanju brown cap) in addition to high-contrast colors.
- **Reduced Motion**: Compatible with user's system preferences.
